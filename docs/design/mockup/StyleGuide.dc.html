The power strip

Running Starting or stopping Stopped Not read from AWS yet Error
One light per VM. Groups are separated and run in start order, left to right. It replaces "0/6" pills, the donut chart and the four count tiles, and is the only place green appears outside Start buttons.

Words

Sentence case. Name things the way people do: "Lock environment", not "Acquire lock". No property names or HTTP codes on screen.

Controls

Every button and switch has a visible or spoken name. Icons go with words. Show only what the person may use.

States

Empty, off and no-access screens say what's going on and offer the next step. Never a blank page.

Layout

Title, one summary line, actions on the right, then content. Pages scroll; panels don't. 44 px touch targets on phones.
